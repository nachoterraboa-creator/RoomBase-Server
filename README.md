### RoomBase-Server

Servidor oficial de RoomBase, una extensión multijugador para PenguinMod Desktop, desarrollada por TwoTimeLikesAzure Productions.

# 📌 Acerca del proyecto

RoomBase-Server es el servidor encargado de gestionar la comunicación multijugador de RoomBase.

Su objetivo es permitir que los proyectos de PenguinMod puedan compartir salas e interactuar con otros jugadores en tiempo real.

# ⚙️ Tecnologías

* Node.js
* WebSocket
* JavaScript

# 🚀 Características previstas

* Crear y unirse a salas.
* Gestionar jugadores conectados.
* Asignar identificadores de jugador.
* Sincronizar información entre participantes.
* Transmitir mensajes en tiempo real.

# 📁 Organización

El proyecto utiliza una estructura modular para mantener el código organizado y facilitar su mantenimiento.
